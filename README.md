# Mastercard Cybersecurity Job Simulation — Internship Report

Internship report and presentation submitted for the B.Tech (Computer Science and Engineering)
programme at IILM University, Greater Noida, U.P.

## Overview
This repository contains the documentation for the **Mastercard Cybersecurity Job Simulation**,
a virtual work experience programme completed via [Forage](https://www.theforage.com/) in
September 2026. The simulation covered two practical tasks from Mastercard's Security Awareness
Team workflow:

- Designing a phishing email simulation
- Interpreting phishing simulation results
